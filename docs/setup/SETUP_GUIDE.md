# MSPM0G3507 两驱小车开发与验收指南

本指南描述当前代码真正具备的能力、已确认接线和逐级验证流程。它不是实车
已通过验收的声明。

## 1. 当前软件状态

当前 `MSPM0G3507_LineFollowing_Car/empty.c` 初始化 SysConfig、电机 UART、
定时器和 Motor Safety，随后循环执行：

```text
Scheduler_Run()
LineWalking()
Motor_Safety_Service()
delay_ms(10)
```

因此当前入口仍运行基础 `LineWalking()` 循迹。`BSP/CarControl/` 中的
`CarRoute` 已实现非阻塞、故障闭锁状态机，但 **CarRoute 尚未接入 empty.c**。
在完成电机反馈、按键启动语义和硬件验收前，不得把文档中的路线模块描述为
当前烧录后会自动执行的功能。

距离和角度运动依赖编码器脉冲、有效轮径、左右极性及偏航标定；这些数据尚未
在组装车上确认，所以相关动作当前保持不可用。摄像头尚未购买，本阶段无视觉
模块、视觉协议或 SysConfig 预留改动。

## 2. 已确认硬件映射

| 功能 | 引脚/通道 | 说明 |
|---|---|---|
| UART0 调试 | PA10 TX / PA11 RX | 115200 |
| 电机驱动 UART | PB6 TX / PB7 RX | 115200 |
| L520 两驱 | M2 左轮、M4 右轮 | M1/M3 无驱动轮，命令必须保持零 |
| 灰度通道选择 | PA15 AD0 / PA16 AD1 / PA17 AD2 | GPIO 多路选择 X1～X8 |
| 灰度数字输出 | PA18 OUT | 低电平暂按黑线解释，需逐路实测 |
| MPU6050 | PA12 SCL / PA13 SDA | 3.3 V 软件 I2C，地址通常为 0x68 |
| LED D1/D2 | PB2 / PB3 | GPIO |
| 按键 K1 | PA2 | GPIO 输入 |
| 蜂鸣器 | PB24 | TIMA0 PWM |

灰度模块数据路径是 PA15/PA16/PA17 选通加 PA18 数字读取，不是 I2C 传感器
数据读取。上车前必须确认 X1～X8 的左右顺序以及黑白电平极性。

## 3. 电源硬门槛

所购电池标称 11.1 V、满充 **12.6 V**；扩展/驱动板图片标注输入范围
**5-12 V**。12.6 V 超过标注上限，在取得准确型号数据手册并确认容许电压前：

- 禁止把满充电池接入扩展/驱动板；
- 软件测试阶段禁止接入 12.6 V 电机电源；
- 不用“12 V 电机”标签推断整块驱动板能够承受 12.6 V；
- 首次动力测试必须使用限流、保险和可立即断开的电源方案。

## 4. 数据与安全契约

### 电机命令

所有运动请求必须经过 Motor Safety。启动采用 0→30% 的 1000 ms 软启动；
200 ms 没有新的合法请求时，安全层锁存故障并发送固定零速帧。禁止绕过安全层
直接发送满速或 100% PWM 命令。

### 电机反馈

`CarMotion` 只接受有效且一致的 M2/M4 反馈。反馈时间戳年龄 **>= 200 ms**
即过期，`CarRoute` 必须停车并进入故障态。离线测试不能证明 UART 反馈在实车上
具备正确极性、单位或帧同步。

### 灰度帧

`CarSensorFrame` 目前没有时间戳或序列号。调用者必须在当前控制周期调用
`CarSensor_ReadFrame`，并且仅在调用成功后立即使用该帧；不得复用上一周期的
缓存帧。后续若需要跨任务传递，必须先扩展公开接口加入可校验的新鲜度信息。

## 5. CCS 导入与离线验证

1. 安装并让 CCS Theia 识别 MSPM0 SDK 2.10.00.04、TI Arm Clang 4.0.4。
2. 选择 **File → Import → Existing Projects into Workspace**。
3. 选择仓库下的 `MSPM0G3507_LineFollowing_Car`。
4. 检查工程引用中是否仍有旧的 `E:\workspace_ccstheia` 或旧 TI 安装路径。
5. 断开电机电源，仅连接调试器，执行 **Project → Clean** 与
   **Build Project**。

本工作树当前没有 CCS 生成的 `Debug/` 目录，故 CCS 完整构建仍为待执行，
烧录、目标板运行和串口输出也均未验证。现有 Python 测试与 TI Arm Clang
翻译单元编译不能替代完整工程生成、链接和目标板验收。

离线测试命令：

```powershell
python -m unittest discover -s tests -v
```
