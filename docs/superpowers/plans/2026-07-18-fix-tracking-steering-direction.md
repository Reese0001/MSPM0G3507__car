# 循迹转向方向修复实施计划

## 目标

修复八路循迹模块“应向左转、实车却向右转”的方向反转问题。

## 约束

- 保持 PA15/PA16/PA17 通道选择与 PA18 OUT 输入不变。
- 保持 X1～X8 的对称位置权重不变。
- 保持 M1/M3 零速以及 M2/M4 驱动轮映射不变。
- 不绕过 `Motor_Safety_RequestSpeed()`，保留软启动和 200 ms 看门狗。
- 本轮不调整 KP、KD、速度或丢线周期，只修正实车转向极性。

## 实施步骤

1. 在 `tests/test_tracking_decision_table.py` 添加转向极性回归测试，并先确认测试失败。
2. 在 `app_irtracking.c` 定义 `TRACKING_STEERING_POLARITY (-1)`。
3. 正常循迹和丢线恢复的控制输出统一乘以该极性。
4. 更新 README，说明位置权重与实车角速度极性的职责边界。
5. 运行完整离线测试和 CCS clean build。
6. 重新生成供 UniFlash 串口 BSL 使用的 TI-TXT 镜像。
7. 在独立分支提交修改，等待实车架空轮复测。

## 验证标准

- 转向极性回归测试经历 RED → GREEN。
- 全部 Python 合同测试通过。
- CCS 工程全量编译成功并生成 `.out`。
- TI-TXT 以 `@0000` 开始、以 `q` 结束。
- 实车测试前关闭电机主电源并架空驱动轮；烧录后先低速验证左偏是否产生左转修正。

## 风险说明

离线测试能证明两个控制出口使用同一修正符号，但不能代替机械方向验证。最终结论必须以架空轮低速测试为准。
