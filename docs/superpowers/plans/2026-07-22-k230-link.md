# K230 Vision Link Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 建立 K230 豪华版与 MSPM0 之间可校验、可超时、不会直接控制电机的视觉事件链路。

**Architecture:** UART ISR 只写环形缓冲，协议解析器增量消费 `$长度,ID,数据#\n`。长度是从 `$` 到 `#` 的全部字符数，换行不计入；消息 ID 为两位十进制。K230 Python 端用同一帧编码器生成事件，MSPM0 仅发布带时间戳和置信度的快照。

**Tech Stack:** MSPM0 UART、C11、Python unittest、CanMV/K230 MicroPython、64GB TF 卡。

## Global Constraints

- 分支：`codex/k230-link`，基于 modular-foundation 审核提交。
- PA21 TX→IO10/RX、PA22 RX←IO9/TX、115200、共地。
- 兼容厂家 ID 01～17；第一阶段只启用明确配置的 ID，未知 ID 丢弃并计数。
- 最大 MCU 帧长固定 128 字节；禁止动态分配。
- K230 不得发送电机速度命令；模块层不得 include motor 头。
- 本分支不永久修改 `empty.syscfg`。

- [ ] **Step 2: 实现编码器**

```python
def encode_frame(event_id: int, fields: list[object]) -> str:
    if not 1 <= event_id <= 99:
        raise ValueError("event_id")
    payload = f"{event_id:02d}," + ",".join(str(v) for v in fields)
    length = len(payload) + 1 + 1 + 2 + 1
    while True:
        frame = f"${length},{payload}#"
        new_length = len(frame)
        if new_length == length:
            return frame + "\n"
        length = new_length
```
