# 转角外侧见线接管设计

## 问题

直角转弯的 `SEEK` 阶段目前把“找到线”和“线已居中”合并为同一条件：
黑线必须连续三帧满足质心误差绝对值不超过 3。实车转弯后即使已有两个
外侧循迹灯亮起，质心误差仍可能为 4 或 6，车辆便继续旋转并在 900 ms
后锁存控制故障，表现为 D1 常亮、D2继续闪烁。

参考 `V2.3.0_B-------5路红外循迹---例程版` 的
`corner_handler()`：急转期间任意循迹通道重新检测到黑线后便停止旋转，
随后交回普通循迹控制。

## 已确认方案

保留现有非阻塞状态机和电机安全层，只分离两个判定：

1. `SEEK` 阶段只判断“可靠见线”：新采样帧中有 1～3 路黑线且置信度不低于
   40。连续三帧可靠见线后结束原地旋转，进入 `SETTLE`。
2. `SETTLE` 阶段沿用现有低速循迹输出，在 300 ms 内由循迹控制器把黑线拉回
   中央。
3. 丢线、陈旧数据、900 ms 寻线超时、全车后退禁止、120 ms 换向停顿和
   ±450 命令限制均保持不变。

## 数据流

`LineFeatures` 新帧 → 检查亮灯数量和置信度 → 累计可靠见线帧 →
`SEEK` 转 `SETTLE` → 使用现有 `LineControlOutput` 低速对中 →
完成后恢复普通循迹。

外侧相邻两灯（质心 ±4 或 ±6）应能触发接管；无灯、超过三灯、低置信度或
重复帧不得推进接管计数。

## 验证

扩展现有 `corner_maneuver_harness.c`：

- 左、右外侧两灯连续三帧时从 `SEEK` 进入 `SETTLE`，不进入故障；
- 重复帧不累计；
- 无灯仍保持 `SEEK`，超时仍故障；
- 所有输出继续满足限幅且不会两轮同时后退。
