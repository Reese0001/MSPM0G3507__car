# 2026 H 题第二问：四路红外循迹设计

## 目标

按下启动键后，小车从 A 点沿黑色环线顺时针行驶一圈，返回 A 点自动停车；总时间不超过 20 s，停车位置相对 A 点基准线的偏差不超过 2 cm。

## 已确认硬件

- 仅使用四路红外光电循迹模块。
- 车头朝前观察，模块排针从左到右为 `GND / X4 / X3 / X2 / X1 / VCC`。
- 连接关系为 `X1 -> PA24`、`X2 -> PA25`、`X3 -> PA26`、`X4 -> PA27`。
- 模块、MCU 和电机驱动板必须共地；模块输出必须是 3.3 V 逻辑电平。
- 旧八路灰度复用器（PA15--PA18）不再参与运行。

## 架构

1. 在 `empty.syscfg` 配置 PA24--PA27 为数字输入。
2. 用四路并行采样器替代旧的八路选择-等待-采样扫描器，每 2 ms 发布一个四位 `black_bits` 快照。
3. 采样层保留输入极性和左右顺序的配置项；启动前在 OLED 上显示 X1--X4 原始状态，用黑/白底实测确认，而不是依赖模块丝印推断。
4. 位置解码使用四个逻辑位置权重 `[-3, -1, +1, +3]`。黑线偏左或偏右时产生差速请求；外侧探头压线时降低基准速度并提高转向量。
5. 丢线时沿最后可靠方向低速寻线；噪声帧短时保持最近一次有效请求，超过保持时间后再进入寻线。
6. 起跑后必须先连续确认已离开 A 点的横向启停线；完成最短有效行驶时间后，再连续确认横向满黑标记，立即停止并冻结计时。

## 状态与数据流

`GPIO -> FourLineScanner -> LinePosition -> LineFollower -> Drive`

按键启动时同时启动 `LapTracker` 和 `Drive`。`LapTracker` 的状态为 `WAITING -> LEAVING_START -> RUNNING -> FINISHED`：只有离开启动标记后才能接受回到 A 点的满黑标记，避免刚启动就停车。

## 电机安全边界

不改变 `Drive` 模块现有约束：启动占空比渐进 ramp、5 ms 指令发送、200 ms 指令看门狗、方向反转前零速等待，且任何停止请求优先立即下发零速。首次上电测试必须架空驱动轮，并可随时切断 12.6 V 电源。

## 验收与测试

1. USB 供电下，在白底和黑线位置逐个读取 OLED 的 X1--X4，确认逻辑极性、左右映射和同时满黑模式。
2. 驱动轮架空，确认按键前为零速；按键后软启动；停止、传感器失效与控制请求超时均输出零速。
3. 低速跑完整环线，记录 OLED 显示时间并验证仅在离开后返回 A 点时停车。
4. 逐步调节速度与停车判定连续帧数，使完整一圈时间不超过 20 s、停车偏差不超过 2 cm。

## 非目标

本变更只覆盖 H 题第二问，不实现摆杆滚球控制、图传、B 点分段计时或题目第 3--6 问。
