# 差速倒退式丢线恢复设计

## 目标

当八路循迹在直角或急弯处丢线时，小车先沿上一帧有效左右轮差速命令的反向轨迹低速倒退，退回到更接近最后有线位置的区域，再按趋势预测方向单向旋转找线。倒退用于缓冲和回退，不改变现有位置环、角度环和电机安全层职责。

## 状态流

```text
FOLLOW
  └─ LOST → REVERSE → SEEK_LEFT/SEEK_RIGHT → ALIGN → FOLLOW
```

- `FOLLOW`：每次有效循迹输出都保存最终左右轮命令。
- `REVERSE`：输出上一帧左右轮命令的负值，保持差速比例；命令限幅到低速。倒退阶段持续时间必须覆盖电机方向互锁的刹停等待，再保留实际倒退时间。
- `SEEK_LEFT/SEEK_RIGHT`：倒退结束后只按三帧位置趋势预测的方向原地旋转，不来回换向。
- `ALIGN`：连续 3 个可信新帧后低速对齐，再恢复正常循迹。
- 没有有效历史轮速时，`REVERSE` 使用低速等速倒退兜底。

## 数据边界

- 倒退只由 `LineRecovery` 生成，`line_motion` 继续负责位置解码、查表、串级 PID 和趋势预测。
- `MotionRequest` 允许负左右轮命令，但仍必须经过 `MotorSafety` 的方向互锁、软启动、限幅和看门狗。
- 恢复策略不直接操作 UART 或 PWM。
- 过期传感器、急停和非法状态仍进入 `STOPPED`，不执行倒退。

## 参数起点

- 倒退命令：上一帧左右轮命令按比例缩放，单轮绝对值不超过 60。
- 总倒退窗口：260 ms，其中包含 120 ms 方向互锁等待，保证至少约 100 ms 实际倒退。
- 倒退期间若重新获得连续可信线帧，可提前进入 `ALIGN`；否则窗口结束后进入预测方向搜索。

## 验收条件

1. 丢线首帧进入 `REVERSE`，左右轮均为非正向命令，且左右差速比例与上一帧一致。
2. 没有上一帧命令时，倒退命令为低速等速负值。
3. 倒退结束后只进入预测方向对应的 `SEEK_LEFT` 或 `SEEK_RIGHT`。
4. 倒退不会绕过电机方向互锁，正常循迹和安全停止行为不回退。
5. 新增合同测试和主机 harness；全量测试、clean 编译和 TI-TXT 生成必须通过。
