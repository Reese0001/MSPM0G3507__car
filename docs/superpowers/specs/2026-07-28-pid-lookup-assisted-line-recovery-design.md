# PID + 开环查表辅助循迹与单向找线设计

## 1. 目标

在保留现有“位置外环 + MPU6050 角度内环”串级 PID 的前提下，增加 M0 八路循迹常用的开环查表辅助方法：2 ms 读取八路灰度、解码 15 个精准位置，查表给出动态平均速度和前馈差速，再由 PID 追加闭环修正。丢线后根据近期位置趋势锁定方向，沿该方向持续找线，不倒车、不反向、不往返摆动。

本次不是用查表替换 PID，而是采用“查表前馈 + PID反馈”的混合控制。

## 2. 已确认硬件与安全约束

- X1 位于车头右侧，X8 位于车头左侧；`bit0=X1`、`bit7=X8`。
- 按下 RESET 后等待 K1，按下 K1 才允许电机启动。
- 保留电机软启动、M2/M4 映射、UART 协议、命令限幅、方向保护和通信看门狗。
- 普通循迹、对准和丢线恢复均不得给任一车轮负速度。
- 普通丢线不能停车；只有急停、线路采样过期或电机安全故障可以停车。
- 不修改现有 MPU6050 卡尔曼滤波底层。

## 3. 活动控制链

活动数据流固定为：

1. **2 ms 灰度采样**：读取 X1..X8，发布一帧位图和新序号。
2. **15 位置解码与防抖**：合法单点或相邻双点映射为 `-7..+7`；负数表示线路在左，正数表示线路在右。
3. **开环查表前馈**：位置查表得到基础平均速度 `base` 和前馈差速 `feedforward_turn`。
4. **串级 PID反馈**：位置环根据误差产生目标转向，MPU6050 角度环根据 yaw/yaw-rate 产生附加修正 `feedback_turn`。
5. **融合与统一限幅**：`final_turn = feedforward_turn + feedback_turn`，再合成左右轮。
6. **恢复状态机**：仅在丢线时接管输出，锁定预测方向后持续单向找线。
7. **电机安全层**：最后执行 K1 门控、软启动、限幅和故障保护。

每层只做一种职责。查表模块不保存 PID 状态；PID 模块不复制位置速度表；恢复模块不修改 PID 参数。

### 3.1 重构约束

本次必须替换受影响职责，禁止在旧逻辑外继续叠加条件：

- 删除串级控制器内部的 `forward_by_position` 和重复速度策略，由查表模块成为唯一位置速度表；
- 在串级控制器原有计算流水线内融合前馈，不新增第二套并行控制器、包装器或功能开关；
- 将恢复状态机重写为五个明确状态，删除前行试探、定时反向、负轮速和旧状态的兼容分支；
- 三帧预测只保留位置历史和 `int8_t` 方向输出，不复制事件分类、PID或电机输出；恢复器只接收该方向值，不接收旧的趋势分类结构；
- `line_motion` 只负责编排数据流，不内嵌查表、PID、预测或恢复公式；
- 未调用的旧模块可以保留在目录中供以后手动启用，但不得链接进活动固件，也不得由活动路径调用。

验收不仅检查新功能存在，还要检查旧的重复数组、旧搜索状态、定时翻转表达式和负找线速度已经从活动代码中消失。

## 4. 15 位置与固定接线

合法位置映射保持：

| 传感器图案 | 位置 |
|---|---:|
| X8 | -7 |
| X8+X7 | -6 |
| X7 | -5 |
| X7+X6 | -4 |
| X6 | -3 |
| X6+X5 | -2 |
| X5 | -1 |
| X5+X4 | 0 |
| X4 | +1 |
| X4+X3 | +2 |
| X3 | +3 |
| X3+X2 | +4 |
| X2 | +5 |
| X2+X1 | +6 |

相邻位置立即接受；跨越较大的跳变必须连续出现 2 帧才接受。丢线、宽黑和分离噪声不更新稳定位置历史，从而避免线路抖动污染趋势。

## 5. 开环查表辅助

查表输出是 PID 的前馈起点，不是最终电机命令。建议初始表：

| `abs(position)` | `base` | `abs(feedforward_turn)` |
|---:|---:|---:|
| 0 | 140 | 0 |
| 1 | 140 | 0 |
| 2 | 130 | 12 |
| 3 | 115 | 28 |
| 4 | 95 | 45 |
| 5 | 80 | 60 |
| 6 | 70 | 65 |
| 7 | 60 | 60 |

- 位置在左时前馈差速为正，使左轮慢、右轮快。
- 位置在右时前馈差速为负，使右轮慢、左轮快。
- `-1/0/+1` 的查表差速均为 0，并进入 PID 中心死区，避免直线时小误差和微分噪声造成左右摆动。
- 表中 `base` 取代串级控制器内部重复的 `forward_by_position`；速度策略只保留一份。

## 6. PID反馈与融合

现有位置环、角度环和已经调过的参数作为初始参数保留：

- 位置环：`KP=14.0`、`KD=0.010`；
- 角度环：`KP=1.5`、`KD=0.55`；
- MPU6050 新鲜时使用角度环；IMU 过期时仅退化到位置环，不取消查表前馈。

融合规则：

```text
base              = lookup(position).base
feedforward_turn  = lookup(position).diff
feedback_turn     = cascade_pid(deadband_position, imu)
final_turn        = feedforward_turn + feedback_turn
left              = base - final_turn
right             = base + final_turn
```

融合后统一执行：

- 转向变化率限制，防止一帧内突变；
- `abs(final_turn) <= base`，保证两轮不出现负速度；
- `0 <= left/right <= 140`，同时继续受电机安全层上限 450 保护。

当位置为 `-1/0/+1` 时，送入位置 PID 的有效误差为 0，位置微分状态同步归零；查表前馈也为 0。超出死区后 PID 正常工作，不删除位置环或角度环。

## 7. 丢线趋势预测

只记录最近三帧可信精准位置 `p0、p1、p2`，其中 `p2` 最新。首次丢线时计算：

`prediction = p2 + (p2 - p1) + (p1 - p0)`

- 结果小于 0：锁定向左找线；
- 结果大于 0：锁定向右找线；
- 结果为 0：使用最近一次非零位置方向；
- 上电无历史：固定向右，并标记回退方向。

方向只在“正常有效 → 首次丢线”的边沿锁定一次。持续丢线期间不更新、不翻转、不重新预测。

## 8. 单向持续找线

- 向左：左轮 `0`，右轮以正速度前进；
- 向右：右轮 `0`，左轮以正速度前进。

初始找线速度为 100。MPU6050 只用于显示相对丢线航向，并在 yaw-rate 过高时把找线速度限制为 80，防止跨过黑线；任何角度阈值都不得改变方向。即使旋转超过 360°，只要线路采样仍新鲜且尚未重新捕获，就继续沿原方向找线。

IMU 过期时仍以固定低速沿锁定方向找线，并显示 `IMU STALE`。

## 9. 重新捕获

“可信帧”必须同时满足：线路采样新鲜、解码类型为精准位置、序号为新帧。连续 3 帧可信才进入 `ALIGN`；重复序号或中间无效帧会清零计数。

`ALIGN` 持续 300 ms，继续使用“查表前馈 + PID反馈”，但把左右轮限制在 `0..80`。若对准期间再次丢线，沿原锁定方向继续找线；稳定回到 `FOLLOW` 后才允许下一次重新预测。

## 10. 状态与 OLED

恢复状态只保留：

- `FOLLOW`；
- `SEEK_LEFT`；
- `SEEK_RIGHT`；
- `ALIGN`；
- `SAFE_STOP`。

OLED 流动日志显示 `LINE FOLLOW`、`LINE SEEK L/R`、相对 yaw、`IMU OK/STALE`、`LINE ALIGN` 和明确的安全停机原因。OLED 只读取诊断快照，不阻塞调度器，也不控制电机。

## 11. 验证要求

主机测试必须证明：

- 2 ms 周期、X1/X8 方位和 15 位置映射正确；
- 跳变防抖保持有效；
- 查表前馈左右对称，`-1/0/+1` 为零差速；
- 串级 PID 仍在活动链，查表前馈确实叠加到 PID反馈；
- MPU6050 新鲜与过期时 PID 行为不同；
- 最终左右轮始终非负且不超过 140；
- 三帧预测能锁定左/右；
- 丢线后经过任意时间和任意 yaw 均不翻转方向；
- 连续 3 帧才能恢复，ALIGN 后返回融合控制；
- 急停和采样过期仍能安全停车；
- K1、软启动、看门狗和 M2/M4 映射没有回退。

完成后必须先清理旧对象和构建缓存，再运行全量测试和 TI Arm Clang 完整构建，生成新的 `dist/firmware/MSPM0G3507_LineFollowing_Car.txt`，记录时间戳和 SHA-256。
