# 八路灰度趋势识别与弯道恢复设计

日期：2026-07-23  
适用分支：`codex/line-following-burn`

## 1. 目标

在不增加硬件、暂不使用 IMU 的条件下，使用八路灰度传感器的连续帧识别并通过以下赛道：

- 普通直线与缓弯；
- 连续黑线的小半径急弯；
- 连续黑线的发卡弯；
- 连续黑线的标准 90° 方形直角；
- 趋势后短暂全灭的直角；
- 没有弯道趋势的普通丢线。

同时解决绕圈后再次经过同一弯道时识别不一致的问题。每次稳定重新上线后必须清空本轮趋势和恢复状态，使下一圈重新识别。

## 2. 当前问题

当前尖弯恢复只读取丢线前最后一帧 `last_seen_error`。即使此前已检测到外侧灯，只要丢线前一帧误差回到普通范围，尖弯证据就会被覆盖。车辆每圈进入弯道的位置略有差异，因此同一弯道可能第一圈触发急转、下一圈只执行大半径搜索。

此外，单一的“普通循迹/全灭恢复”不能覆盖连续黑线的发卡弯，因为这些弯道可能始终有黑线，不能等待 `LINE_EVENT_LOST` 才处理。

## 3. 模块边界

新增独立模块 `modules/line_tracking/line_trend_detector.{h,c}`。该模块只分析灰度趋势，不直接控制电机。

输入：

- `LineEstimate.error`
- `LineEstimate.event`
- 灰度快照的 `black_bits`
- 帧序号与时间戳

输出 `LineTrendResult`：

- `LINE_TREND_NORMAL`
- `LINE_TREND_TIGHT_LEFT` / `LINE_TREND_TIGHT_RIGHT`
- `LINE_TREND_HAIRPIN_LEFT` / `LINE_TREND_HAIRPIN_RIGHT`
- `LINE_TREND_RIGHT_ANGLE_LEFT` / `LINE_TREND_RIGHT_ANGLE_RIGHT`
- 趋势有效性、方向和时间戳

`line_controller` 根据仍然可见的黑线和趋势等级选择普通、紧弯或发卡控制。`line_recovery` 只在直角确认或普通丢线后接管。安全监督仍是所有运动请求的最终仲裁者。

## 4. 趋势识别

趋势检测器保存以下有限历史：

- 当前符号方向；
- 连续同向帧数；
- 连续向外移动次数；
- 当前和近期最大绝对误差；
- 最近到达外侧区域的时间；
- 最近一次宽黑事件；
- 趋势开始时间。

默认判据：

- 向外移动：相邻有效帧绝对误差增加，允许一次持平；
- 同向：误差符号不变，中心附近的零误差不改变已确认方向；
- 外侧区域：`|error| >= 4`；
- 最外侧区域：`|error| >= 6`；
- 直角关联窗口：到达外侧区域后 200 ms；
- 稳定退出：误差连续 3 帧回到 `|error| <= 3`；
- 稳定重新上线：连续 3 帧有效且置信度不低于 40。

分类：

1. **连续紧弯**：同向向外移动至少两次，进入 `3 <= |error| < 6`，且黑线仍存在。
2. **连续发卡弯**：完整同向外移趋势后，`|error| >= 6` 连续 3 帧，且黑线仍存在。
3. **连续 90° 直角**：完整同向外移趋势到达外侧后，在 200 ms 内出现 `LINE_EVENT_WIDE_BLACK` 或至少 4 路同时有效的横线模式。
4. **全灭型直角**：完整同向外移趋势到达外侧后，在 200 ms 内出现全灭。
5. **普通丢线**：全灭但不存在完整同向外移趋势。

单独出现外侧灯、宽黑、多灯或一次误差跳变均不能确认直角。

## 5. 运动策略

### 5.1 普通循迹

- `|error| < 3`
- 保持 `KP = 28`
- 最高直线命令保持 350
- 保留转向限斜率和现有软启动

### 5.2 连续紧弯

- 基础前进命令初值 140；
- 转向命令初始上限 100，使初始轮速范围为内轮 40、外轮 240；
- 内轮不反转；
- 趋势反向或连续 3 帧回到 `|error| <= 3` 后平滑退出。

### 5.3 连续发卡弯

- 内轮命令初值 -60；
- 外轮命令初值 140；
- 黑线始终参与闭环，不能按固定时间盲转；
- 连续 3 帧回到 `|error| <= 3` 后退出并恢复转向限斜率。

### 5.4 连续或全灭型 90° 直角

- 左直角：左轮 -80，右轮 120；
- 右直角：左轮 120，右轮 -80；
- 转动期间持续读取八路灰度；
- 连续 3 帧重新检测到可信黑线后，进入 300 ms 的低速对正；
- 对正完成后清空趋势历史并恢复普通循迹。

### 5.5 普通丢线与原轨迹倒退

没有完整弯道趋势时：

1. 全灭连续 3 帧；
2. 按最后方向低速向前圆弧搜索 500 ms；
3. 两轮停车 120 ms，禁止直接正反切换；
4. 沿相同圆弧倒退 700 ms：
   - 左圆弧：从 `80/120` 切换为 `-80/-120`；
   - 右圆弧：从 `120/80` 切换为 `-120/-80`；
5. 任一阶段连续找到可信黑线 3 帧，立即进入低速对正；
6. 仍找不到线则安全停车，不循环盲跑。

## 6. 状态清理与多圈一致性

下列情况必须清空趋势检测器和恢复计数：

- 初始化或人工复位；
- 对正完成并回到普通循迹；
- 安全监督进入故障；
- 恢复超时并停车。

不能在单帧重新看到黑线时立即清空趋势；必须等连续 3 帧确认重新上线，防止噪声造成状态抖动。

## 7. 安全约束

- 所有速度绝对值不超过现有 450 硬上限；
- 保留电机软启动和 200 ms 命令看门狗；
- 正反切换前停车至少 120 ms；
- 急停、请求过期、传感器陈旧和电机故障立即覆盖趋势与恢复输出；
- 无线、IMU、视觉和超声波仍保持当前未安装配置，不引入未确认硬件；
- 恢复动作必须有总超时，禁止无限前进、倒退或旋转。

## 8. 测试与验收

自动测试至少覆盖：

- 左右镜像的普通弯、紧弯、发卡弯；
- 中间到同侧外灯再全灭的直角序列；
- 中间到同侧外灯再宽黑的连续方形直角序列；
- 单次外灯跳变、单次宽黑和非连续噪声不误判；
- S 弯方向切换会重置旧方向趋势；
- 连续黑线发卡弯不进入丢线恢复；
- 普通丢线按前进、停车、原弧倒退顺序输出；
- 任一恢复阶段连续 3 帧重新上线后退出；
- 两圈重复输入同一弯道序列，两次均产生相同分类；
- 急停、陈旧数据、恢复超时全部输出停车；
- 所有命令满足速度上限和正反切换停车间隔。

实车验收顺序：

1. 架空车轮验证左右方向和正反切换停车；
2. 低速测试方形连续直角；
3. 低速测试图片中的连续急弯和发卡弯；
4. 制造普通丢线，验证沿原圆弧倒退；
5. 连续运行至少两圈，确认同一弯道重复识别；
6. 每次只调整一个配置参数并独立提交。

## 9. 非目标

- 本阶段不使用 MPU6050 或其他 IMU；
- 不根据地图预存弯道位置；
- 不引入 RTOS；
- 不改变八路灰度、电机驱动或底盘硬件；
- 不以无限搜索替代安全停车。
