# YbImu 九轴姿态模块校准与台架验收清单

本清单适用于地址 `0x23` 的 YbImu 九轴模块。校准和方向验收期间电机必须保持零速；本功能分支不修改 SysConfig，也不调用 `Motor_Safety_Arm()`。

## 1. 断电与总线检查

- [ ] 断开 12.6V 电池和电机动力插头，车轮悬空或电机线断开。
- [ ] 按模块丝印和厂家资料确认 VCC 电压；不得根据接口颜色猜测供电。
- [ ] 模块与 MSPM0G3507 共地。
- [ ] 计划连接 PA12=SCL、PA13=SDA；最终连接前确认两线未接反。
- [ ] 检查 SDA/SCL 上拉电压不超过 3.3V；不得把 5V 上拉直接送入 MCU。
- [ ] 总线配置为 100kHz，并确认扫描到唯一 7-bit 地址 `0x23`。

## 2. 版本与静态数据

- [ ] 读取厂家版本寄存器并记录版本号。
- [ ] 模块静止放平，连续记录不少于 60s 的 gyro、Euler、quat 和 mag 数据。
- [ ] 统计 60s yaw 漂移、最大跳变和有效快照比例。
- [ ] 100Hz 数据年龄持续小于项目允许的 50ms 过期阈值。
- [ ] 任一分步 I²C 事务失败时，不更新时间戳，不发布半组新数据。

## 3. 坐标方向确认

- [ ] 记录模块丝印坐标与车体前、左、上的对应关系。
- [ ] 分别沿 X/Y/Z 正方向转动或倾斜，确认三个 gyro 与 Euler 分量的符号。
- [ ] 小车原地左转时记录 yaw 符号，原地右转时符号必须相反。
- [ ] 根据实测结果修改 `ybimu_config.h` 的轴来源和正负号；未验证前保持 identity 配置且不得用于闭环转弯。
- [ ] 四元数顺序按厂家资料确认为 w、x、y、z。

## 4. 非阻塞校准

- [ ] IMU 校准前将模块稳定放平，发送 `0x70=0x01`，过程中不得移动。
- [ ] 每 100ms 读取一次 `0x70` 状态；7s 内未成功必须进入 FAILED。
- [ ] 九轴磁校准发送 `0x71=0x01`，手持模块完成 8 字动作，并覆盖多个朝向。
- [ ] 每 100ms 读取一次 `0x71` 状态；60s 内未完成必须失败关闭。
- [ ] 用户取消只终止本机状态机并保持数据无效；厂家未定义停止写命令，不得臆造寄存器值。
- [ ] 校准 RUNNING、FAILED 或快照过期期间，安全监督层必须拒绝运动请求。

## 5. 磁场健康门控

- [ ] 电机断电时记录静止磁场模长、短时变化和 yaw 抖动。
- [ ] 仅给电机驱动供电但保持零速，重复记录并比较差异。
- [ ] 架空轮、低于 30% 输出时再次记录；该步骤需另行确认电机测试 Checklist 后才能执行。
- [ ] 磁场模长超出配置范围或相邻样本变化过大时，`magnetic_heading_healthy=false`。
- [ ] 磁航向不健康时允许保留 gyro/Euler 诊断数据，但不得用磁航向修正闭环转弯。
