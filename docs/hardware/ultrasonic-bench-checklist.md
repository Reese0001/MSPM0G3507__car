# HC-SR04 前向急停模块台架验收清单

本清单只用于固定朝车头正前方的 HC-SR04。模块只发布距离快照，最终由安全监督层判断限速或锁存急停；不得直接控制电机。

## 1. 断电接线检查

- [ ] 断开 12.6V 电池和电机动力插头，车轮悬空或电机线断开。
- [ ] 用万用表确认扩展板 `5V` 输出在允许范围内，再连接 HC-SR04 `VCC`；禁止把 12.6V 直接接到传感器。
- [ ] HC-SR04 `GND`、扩展板 `GND` 和 MSPM0G3507 `GND` 共地。
- [ ] `Trig` 规划连接 PA26；本分支尚未修改 SysConfig，集成前不得按该引脚表直接烧录运行。
- [ ] `Echo` 经电阻分压后连接 PA27，禁止将约 5V Echo 直接送入 MCU。
- [ ] 分压器推荐起点为 Echo 侧 2.0kΩ、GND 侧 3.3kΩ；若使用其他阻值，先计算比例并实测。
- [ ] 上电前检查 VCC-GND 无短路、Trig 与 Echo 未接反、分压中点确实连接 PA27。

## 2. 电平验收

- [ ] 只给 MCU、扩展板和超声波模块供电，保持电机动力断开。
- [ ] 万用表确认传感器 VCC 接近 5V；若电压明显偏离，立即断电排查。
- [ ] 示波器确认 Trig 为约 10µs 高脉冲，重复周期不短于 60ms。
- [ ] 示波器在分压后的 PA27 节点测量 Echo，高电平最大值必须不超过 3.3V。
- [ ] 分压前后波形均无明显振铃或悬空；不满足时不得连接 MCU 输入。

## 3. 固定距离测试

传感器固定朝车头正前方，探头平面与目标板平行，前方无遮挡。每个距离记录至少 10 次结果。

| 标准距离 | 参考 Echo 脉宽 | 中位数误差 | 最大误差 | 有效帧比例 | 结果 |
| --- | ---: | ---: | ---: | ---: | --- |
| 10cm | 约 583µs |  |  |  |  |
| 20cm | 约 1166µs |  |  |  |  |
| 40cm | 约 2332µs |  |  |  |  |
| 80cm | 约 4665µs |  |  |  |  |

建议初始验收线：各点中位数误差不超过 10mm、单次最大误差不超过 20mm、有效帧比例不低于 95%。正式阈值应在车体安装完成后重新标定。

## 4. 超时与非阻塞检查

- [ ] 测量过程中快速移除目标或使用吸声材料，确认无有效回波时在 30ms 超时后发布 `valid=false`、`health=DEGRADED`。
- [ ] 连续观察触发间隔，任意两次 Trig 上升沿间隔不得短于 60ms。
- [ ] 传感器断开或无响应时，主循环、按键扫描、蜂鸣状态机和 200ms 电机 watchdog 仍持续运行。
- [ ] Echo 长时间保持高或低时不得出现 `delay_ms()`、等待 Echo 的循环或主循环卡死。
- [ ] 恢复正常目标后，后续有效快照可恢复为 `valid=true`、`health=OK`。

## 5. 装车复验

- [ ] 模块牢固朝向车头正前方，左右偏角和俯仰角已记录。
- [ ] 探头声锥范围不被车壳、线束、轮胎或地面遮挡。
- [ ] 先断开电机动力完成传感器验收，再进行架空轮测试。
- [ ] 未经单独确认，不调用 `Motor_Safety_Arm()`，不得进行落地运动测试。
- [ ] 保存示波器截图、固定距离记录、无回波日志和最终分压电阻实测值。
