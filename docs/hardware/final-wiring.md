# 最终接线步骤

状态：**预接线版 - 等待实物照片复核接口方向与灰度模块类型**

## 0. 接线前

1. 关闭扩展板开关，拔掉电池、USB、K230 Type-C 和电机动力线。
2. 万用表确认所有电源端无电。
3. 将小车轮子架空；电机动力线留到最后。
4. 所有模块必须共地，但不要把 5V 接到任意 3.3V GPIO。

## 1. 九轴 IMU（IIC，100kHz）

| IMU | MSPM0/扩展板 | 说明 |
|---|---|---|
| 3V3 | 3.3V | 资料允许 3.3V/5V，本项目选 3.3V |
| GND | GND | 共地 |
| SCL | PA1 | 软件 IIC 时钟 |
| SDA | PA0 | 软件 IIC 数据 |

模块使用 7 位地址 `0x23`。当前循迹只读取 Z 轴角速度作为可旁路阻尼，不依赖磁校准和绝对 yaw；最终正负号通过 OLED 的 `G±nnn` 实测后在 `YBIMU_BODY_Z_SIGN` 配置。

## 2. 固定前向 HC-SR04

| HC-SR04 | MSPM0/扩展板 | 说明 |
|---|---|---|
| VCC | 5V | 先通过电源验收 |
| GND | GND | 共地 |
| Trig | PA26 | 3.3V GPIO 输出 |
| Echo | 电平转换/分压输入 | **禁止直接接 PA27** |
| 转换后输出 | PA27 | TIMG8_CCP1 捕获 |

分压可采用 Echo→10kΩ→PA27，PA27→15kΩ→GND（5V 约降为 3.0V）；上电前确认 PA27 端高电平不超过 3.3V。传感器固定朝车头正前方，只用于前向限速和急停，不参与转弯测距。

## 3. K230 豪华版（64GB TF）

| K230 | MSPM0/扩展板 | 说明 |
|---|---|---|
| 5V | 经验收的 5V/≥1A 电源 | 扩展板 5V 未通过带载测试前，改用独立合规 5V 电源 |
| GND | GND | 两块板必须共地 |
| IO9/TX | PA22/RX | K230 发，MSPM0 收 |
| IO10/RX | PA21/TX | MSPM0 发，K230 收 |

串口为 115200、8N1。先只接 GND/TX/RX，用独立电源验证；确认无反复重启后再整理线束。TF 卡日志默认关闭，开启时保留轮转上限。

## 4. 八路灰度模块

当前代码使用四根信号线：

| 灰度模块 | MSPM0 |
|---|---|
| AD0 | PA15 |
| AD1 | PA16 |
| AD2 | PA17 |
| OUT | PA18 |
| GND | GND |
| VCC | 以实物丝印/说明书确认 |

底盘资料中的另一款“八路巡线”使用 SDA/SCL（PA16/PA15），与当前 AD0/AD1/AD2/OUT 型模块不是同一种接口。未看到实际模块正反面和插座丝印前，**不要按 SDA/SCL 示例接线**。

## 5. 电机驱动与 SSD1306 OLED

> 2026-07-26 FreeRTOS 迁移后，PA10/PA11 不再是调试串口（UART0 已从
> SysConfig 删除），改作 SSD1306 OLED 软件 I2C。调试信息看 OLED 仪表页。

| 功能 | MSPM0 | 对端 |
|---|---|---|
| 电机 UART TX | PB6 | 驱动板 RX |
| 电机 UART RX | PB7 | 驱动板 TX |
| OLED SCL | PA10 | SSD1306 SCL（地址 0x3C） |
| OLED SDA | PA11 | SSD1306 SDA |
| OLED VCC | 3.3V | 禁止接 5V |
| 地 | GND | 所有逻辑板 GND |

OLED 掉线只会使仪表页停止刷新（故障码 OLED-I2C），不会影响循迹与电机。

只使用 M2/M4 两个驱动轮通道。首次接电机前确认零速帧、方向、0→30% soft-start、200ms watchdog 和急停断电手段。

## 6. 分段通电顺序

1. 仅扩展板上电，测 5V/3.3V。
2. 接 MCU，确认串口和 BOOT_SAFE，电机保持断开。
3. 依次接 IMU、灰度、超声波，每接一个就读取健康状态。
4. K230 用通过验收的 5V 单独启动，确认 UART 数据和 300ms stale 检测。
5. 电机轮子架空后最后接动力，先零速，再 10%、20%、30%。
6. 任一模块掉线、超声波≤200mm、看门狗超时或人工停止，M2/M4 必须立即归零。

## 7. 仍需用户照片确认

- 扩展板正反面、5V 输出端丝印和稳压芯片清晰近照。
- 九轴 IMU 正反面及 X/Y 箭头方向。
- 八路灰度模块正反面、插座丝印和线序。
- HC-SR04 插针从正面看时的 VCC/Trig/Echo/GND 顺序。
- K230 通讯接口 IO9/IO10/5V/GND 丝印及线束颜色。
