# 历史参考资料

本目录中的源码仅供协议、驱动和算法对照，不会编译进当前 CCS 工程。

- `motor-controller/`：四路电机驱动板的 MSPM0 通信示例；`firmware/` 中固件运行在外部电机驱动板，不运行在 MSPM0G3507 主控板。
- `eight-tracking/`：MSPM0 双驱八路灰度循迹示例。
- `competition-2024-h/`：2024 H 题两驱比赛逻辑，仅作历史算法参考，不代表 2026 最终方案。
- `mpu6050/`：模块规格、原理图、尺寸图和接线说明。
- `mspm0-two-wheel/`：两驱相关示例的导航索引，不重复存放源码。

当前配置和行为应以工程中的 `empty.syscfg`、`empty.c` 和 `BSP/` 为准。未经硬件确认，不应直接复用历史工程的引脚、电机参数或控制逻辑。
